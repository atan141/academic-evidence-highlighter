# Version snapshots

Each release snapshot has its own folder containing its source, manifest, and packaged ZIP. All version snapshots are visible from the repository's `main` branch under `versions/`.

- [0.16.3](0.16.3/) — earlier finalized Chrome Web Store version.
- [0.17.11](0.17.11/) — previous finalized Chrome Web Store version.
- [0.17.12](0.17.12/) — previous finalized Chrome Web Store version.
- [0.17.13](0.17.13/) — latest version snapshot.

Git branches track separate lines of development, not published versions. Keep version snapshots in these folders; use branches for changes being developed.
