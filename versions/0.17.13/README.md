# Agate: Academic Evidence Highlighter 0.17.13

Latest version snapshot. The previous finalized 0.17.12 snapshot remains available.

- `extension/`: source files for loading the unpacked extension in Chrome.
- `agate-0.17.13.zip`: packaged extension ZIP for the Chrome Web Store release.
- `manifest.json`: repository-layout manifest for this snapshot.

## What changed in 0.17.13

- Renames the extension to Agate: Academic Evidence Highlighter, keeping the same extension ID, so existing users update in place.
- The side panel heading stays Evidence Finder, and the blue A logo is unchanged.
- No permission, storage, or data-handling changes. The store description changed only by the Agate prefix.
